# MiniMax H3 I2V Implementation Plan

> **For agentic workers:** implement task-by-task with TDD. Steps use checkbox syntax.

**Goal:** Add first/last-frame I2V to the existing MiniMax H3 ComfyUI worker without new weights.

**Architecture:** Resolve `first_image` / `last_image` (URL or base64) → stage files in Comfy input → runtime-patch `t2va_api.json` with LoadImage nodes wired to `MiniMaxH3ImageToVideo` `first_frame` / `last_frame`.

**Tech Stack:** Python 3, Pillow, requests (handler), unittest, existing Comfy API graph.

**Spec:** `docs/superpowers/specs/2026-08-12-minimax-h3-i2v-design.md`
