# Fibo-2 candidate image verification — 2026-10-21

Fibo-2 is implemented as a fourth backend of the common image worker.
Base maps to Fibo-2.0-dev for generation/editing; Turbo maps to the separate
Fibo-2.0-edit-turbo checkpoint for editing. The API takes VGL JSON objects
without a conversion LLM. See [contract and examples](../../workers/fibo_2/README.md).

## Source and container tests

The exact CUDA image passed dependency validation, downloader/client help,
all four runtime imports, and handler registration without weights.
Torch 2.9.1+cu128 / torchvision 0.24.1+cu128 / CUDA 12.8; Transformers 5.20.1.
Diffusers is pinned to merged Fibo support, with the existing Qwen native-reference
patch applied successfully.

The separate caption image also passed its 24 tests. Independent source review
found no remaining actionable issues.

Fibo tests cover structured prompt handling, client serialization, ordered
references, Base/Turbo defaults and capabilities, variant ownership, pinned
size validation, interrupted download repair and cache reuse. A CPU-only
controlled subprocess with a FIFO proves that an actual tiny local transformer
loads before later components become available. Tests also prove late-download
and nonzero-final-exit failure propagation, child termination on loading failure,
and release of partially loaded native BF16 weights. These are generated tiny
test checkpoints, not the production Bria weights.
